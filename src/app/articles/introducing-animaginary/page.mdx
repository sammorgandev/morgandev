When building a website for a company as ambitious as Planetaria, making an impression is crucial. Animaginary was developed to deliver animations that are not only visually stunning but also highly performant, leveraging the latest advancements in web technology.

To achieve this, we focused on optimizing every aspect of the animation process, from rendering to execution. Animaginary is hand-written in optimized WebAssembly (WASM), allowing it to animate properties like `height` at 60fps, a feat previously thought impossible on the web.

## The Technology Behind Animaginary

Animaginary utilizes WebAssembly to achieve unparalleled performance. By compiling critical parts of the animation engine to WASM, we ensure that animations run smoothly even on resource-constrained devices.

```js
import { animate } from '@planetaria/animaginary'

export function MyComponent({ open, children }) {
  return (
    <animate.div
      in={open}
      animateFrom="opacity-0 scale-95"
      animateTo="opacity-100 scale-100"
      duration={350}
    >
      {children}
    </animate.div>
  )
}
```

This example demonstrates how Animaginary's API allows developers to create complex animations with minimal code, focusing on the desired effect rather than the underlying mechanics.

## Performance Optimization

To maximize performance, Animaginary employs several optimization techniques:

- **Efficient Rendering**: By minimizing reflows and repaints, Animaginary ensures that animations remain smooth and responsive.
- **Hardware Acceleration**: Animaginary leverages GPU acceleration to offload rendering tasks, freeing up the CPU for other operations.
- **Lazy Evaluation**: Animations are only calculated when necessary, reducing the computational overhead.
